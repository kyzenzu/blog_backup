### `fread` 函数详解

---

#### 函数原型
```c
#include <stdio.h>

size_t fread(void *buffer, size_t size, size_t count, FILE *stream);
```

---

#### 功能说明
从文件流 `stream` 中读取数据到 `buffer` 指向的内存缓冲区中。`fread` 以**元素（单位）** 为基本读取单元，每次读取一个元素，元素的大小由 `size` 指定，读取的元素个数由 `count` 指定。

---

#### 返回值
- **成功**：返回**实际读取的元素（单位）个数**，而不是读取的字节数。
- **到达文件末尾或出错**：返回值小于 `count`。应使用 `feof(stream)` 或 `ferror(stream)` 进一步判断具体原因。
- **返回值类型**：`size_t`（无符号整数）。

> **⚠️ 重要**：`fread` 的返回值是**元素个数**，不是字节数。这与系统调用 `read` 不同（`read` 按字节读取，返回值为字节数）。

---

#### 所需头文件

| 头文件               | 必要性   | 说明                                                         |
| -------------------- | -------- | ------------------------------------------------------------ |
| `#include <stdio.h>` | **必须** | C 标准库规定 `fread`、`fwrite` 等标准 I/O 读写函数的声明及 `FILE` 类型定义位于 `<stdio.h>` 中。 |

---

#### 参数详解

| 参数     | 说明                                                        |
| -------- | ----------------------------------------------------------- |
| `buffer` | 指向内存缓冲区的指针，用于存放读取到的数据                  |
| `size`   | **每个元素（单位）的大小**（字节数）                        |
| `count`  | **要读取的元素（单位）个数**                                |
| `stream` | 指向 `FILE` 结构的文件流指针（由 `fopen`、`fdopen` 等返回） |

---

#### 核心要点

1. **读取单位（元素）**：`fread` 以元素为单位进行读取，每次读取 `size` 字节作为一个完整元素。

2. **总读取字节数** = `size × count`（请求的总字节数）。

3. **返回值含义**：返回的是**成功读取的元素个数**，而不是字节数。

4. **不足一个元素时的处理**：即使文件末尾剩余的数据不足 `size` 字节（即不够一个完整元素），`fread` 仍然会将这些剩余字节读取到 `buffer` 中，但**返回值不会计入这个不完整的元素**（即 `ret` 不会加 1）。

##### 示例说明

```c
// 假设文件大小为 10 字节
char buf[16];
size_t ret = fread(buf, 4, 3, fp);
// 请求：读取 3 个元素，每个元素 4 字节，共 12 字节
// 实际：文件中只有 10 字节，可以完整读取 2 个元素（8 字节），剩余 2 字节不足 4 字节
// 结果：剩余 2 字节仍会读入 buf 中，但 ret 返回 2（只计完整元素个数）
```

---

#### 与 `read` 系统调用的区别

| 特性           | `fread`（标准 I/O）              | `read`（系统调用）             |
| -------------- | -------------------------------- | ------------------------------ |
| **所属层级**   | C 标准库（带缓冲）               | 系统调用（内核接口）           |
| **读取单位**   | 元素（单位），由 `size` 指定     | 字节                           |
| **返回值含义** | 读取的**元素个数**               | 读取的**字节数**               |
| **缓冲区类型** | 用户态缓冲区                     | 内核页缓存（直接到用户缓冲区） |
| **适用场景**   | 结构化数据读取（如数组、结构体） | 原始字节流读取                 |

---

#### 使用示例

```cpp
#include <stdio.h>

long long operator""K(unsigned long long x) { return x * 1024; }
long long operator""M(unsigned long long x) { return x * 1024 * 1024; }
long long operator""G(unsigned long long x) { return x * 1024 * 1024 * 1024; }

int main() {
	FILE* pFile = fopen("./test.txt", "r");
	if (pFile != NULL) {
		char* buf = new char[10M];
		size_t ret = fread(buf, sizeof(char) * 2, 1K, pFile); // 读取1K个元素
		fseek(pFile, 0, SEEK_SET);
		size_t ret1 = read(fileno(pFile), buf, 1K); // 读取1K个字节
		printf("fread: %d\n", ret); // 27 读取元素个数
		printf("read: %d\n", ret1); // 54 读取字节个数
		fclose(pFile);
        delete buf;
	}
	return 0;
}
```

---

#### 注意事项

1. **返回值检查**：调用后应检查返回值是否等于 `count`，若小于 `count`，需用 `feof()` 或 `ferror()` 判断原因。
2. **二进制模式**：读取结构体或非文本数据时，建议以二进制模式打开文件（`"rb"`），避免换行符转换导致数据错乱。
3. **缓冲区大小**：确保 `buffer` 有足够空间容纳 `size × count` 字节的数据，否则可能导致缓冲区溢出。
4. **与 `write` 配对**：`fread` 常与 `fwrite` 配合使用，两者参数含义一致。

---

#### 快速参考

| 函数    | 头文件      | 核心用途                 | 返回值含义     |
| ------- | ----------- | ------------------------ | -------------- |
| `fread` | `<stdio.h>` | 从文件流读取数据到缓冲区 | 读取的元素个数 |

### `fgetc` 和 `fgets` 函数详解

---

#### 1. `fgetc` —— 读取一个字符

##### 函数原型
```c
#include <stdio.h>

int fgetc(FILE *stream);
```

##### 功能说明
从指定的文件流 `stream` 中读取**下一个字符**，并将其作为 `int` 类型返回。该函数会移动文件流内部的读写位置指针。

##### 返回值
- **成功**：返回读取到的字符（转换为 `unsigned char` 后的 `int` 值，范围 0~255）。
- **到达文件末尾（EOF）**：返回 `EOF`（通常为 `-1`）。
- **出错**：返回 `EOF`，并设置 `errno`。

> **⚠️ 重要**：由于 `EOF` 是负值，而有效字符返回的是非负值，因此可以用 `int` 类型的返回值来区分字符和文件结束/错误状态。**不要**将返回值赋给 `char` 类型再判断，否则可能丢失信息。

##### 所需头文件

| 头文件               | 必要性   | 说明                                                         |
| -------------------- | -------- | ------------------------------------------------------------ |
| `#include <stdio.h>` | **必须** | C 标准库规定 `fgetc`、`fgets` 等字符/字符串读取函数的声明及 `FILE` 类型定义、`EOF` 宏定义位于 `<stdio.h>` 中。 |

---

#### 2. `fgets` —— 读取一个字符串

##### 函数原型
```c
#include <stdio.h>

char *fgets(char *str, int n, FILE *stream);
```

##### 功能说明
从指定的文件流 `stream` 中读取一行字符串到 `str` 指向的缓冲区中。最多读取 `n-1` 个字符（留一个位置给结尾的 `\0`）。

##### 返回值
- **成功**：返回 `str`（指向缓冲区的指针）。
- **到达文件末尾或出错**：返回 `NULL`。需使用 `feof(stream)` 或 `ferror(stream)` 进一步判断原因。

##### 所需头文件

| 头文件               | 必要性   | 说明                                                 |
| -------------------- | -------- | ---------------------------------------------------- |
| `#include <stdio.h>` | **必须** | C 标准库规定 `fgets` 函数的声明位于 `<stdio.h>` 中。 |

##### 参数详解
| 参数     | 说明                                                   |
| -------- | ------------------------------------------------------ |
| `str`    | 指向缓冲区的指针，用于存放读取到的字符串               |
| `n`      | 缓冲区大小（最多读取 `n-1` 个字符，末尾自动添加 `\0`） |
| `stream` | 指向 `FILE` 结构的文件流指针                           |

##### 读取终止条件（满足任一即停止）
1. **读取到换行符 `\n`**：换行符**会被读入**缓冲区，然后终止。
2. **读取到文件末尾（EOF）**：终止。
3. **已读取 `n-1` 个字符**：终止（缓冲区满）。

> **注意**：换行符 `\n` 会被 `fgets` 读入并保存在 `str` 中，这与 `gets` 不同（`gets` 会丢弃换行符）。字符串末尾始终会添加 `\0`。

---

#### 3. 文件流内部读写指针

`FILE` 结构体内部维护了**读写位置指针**，记录了当前文件流中下一次读/写操作的位置。

- 每次调用 `fgetc`、`fgets`、`fread`、`fwrite` 等函数，都会**自动更新**该位置指针。
- ⭐**读指针和写指针在同一个文件流中共享同一个位置**（对于 `r+`/`w+` 等读写模式，读写操作**共用同一个位置指针**）。

---

#### 4. 使用示例

```c
#include <stdio.h>

int main() {
    // 以只读方式打开文件
    FILE* pFile = fopen("./test.txt", "r");
    if (pFile != NULL) {
        // 1. 读取第一个字符
        int ch = fgetc(pFile);
        printf("fgetc: [%c]\n", ch);

        // 2. 从当前位置读取一行字符串（最多 1024 字节）
        char buf[1024];
        printf("fgets: [%s]\n", fgets(buf, 1024, pFile));

        // 3. 再次读取一个字符（位于上一行之后）
        printf("fgetc: [%d]\n", fgetc(pFile));

        fclose(pFile);
    }
    return 0;
}
```

**假设 `test.txt` 内容为**：
```
Hello
World
```

**程序输出解析**：

| 调用                      | 读取位置                                                     | 返回值     |
| ------------------------- | ------------------------------------------------------------ | ---------- |
| `fgetc(pFile)`            | 读取字符 `'H'`，位置移到 `e`                                 | `'H'`      |
| `fgets(buf, 1024, pFile)` | 从 `e` 读取到 `\n`，读入 `"ello\n"`（共 5 字符），位置移到下一行开头 | `"ello\n"` |
| `fgetc(pFile)`            | 读取下一行第一个字符 `'W'`，位置移到 `o`                     | `'W'`      |

---

#### 快速参考

| 函数    | 头文件      | 核心用途               | 返回值                  |
| ------- | ----------- | ---------------------- | ----------------------- |
| `fgetc` | `<stdio.h>` | 从文件流读取一个字符   | 字符的 `int` 值或 `EOF` |
| `fgets` | `<stdio.h>` | 从文件流读取一行字符串 | `str` 或 `NULL`         |
