### ls命令

命令ls是list的缩写

其作用是列出指定位置的文件和文件夹

如果没有指定，默认是列出当前位置的文件或者文件夹

显示出来结果如果有颜色，颜色意义如下：

| 文字颜色         | 代表含义                    | 典型文件                  |
| :--------------- | :-------------------------- | :------------------------ |
| **默认色**       | 普通文件                    | 文本文件、日志等          |
| **蓝色**         | 目录（文件夹）              | `Downloads/`、`src/`      |
| **绿色**         | 可执行文件                  | `script.sh`、`a.out`      |
| **红色**         | 压缩包文件                  | `.zip`、`.tar.gz`、`.rar` |
| **青色（浅蓝）** | 符号链接（软链接）          | `link -> /target`         |
| **黄色**         | 设备文件（块设备）          | `/dev/sda`                |
| **粉色/品红**    | 图片/音视频等多媒体文件     | `.jpg`、`.mp3`、`.mp4`    |
| **红色 + 粗体**  | 特殊可执行文件（setuid 等） | `/usr/bin/passwd`         |



常用的参数有

#### -a 列出所有的文件或者文件夹

在Linux系统里面，以 . 开头的文件或者文件夹，一般会被默认视为隐藏的

如果想要查看这些隐藏文件或者文件夹，最好使用-a参数

#### -l 列出详细信息

默认ls只显示名字，并不显示详细信息

加了该参数后，除了会显示名称以外，还会显示文件的权限、所属用户、分组、大小、修改日期

`total` 后面的数字表示**该目录下所有文件（包括子目录）占用的磁盘块（block）总数**。一个块的大小大约是 512 字节

#### -h 增加可读性

和 `-l` 搭配使用，它会做文件大小列单位的转换不需要自己再去算大小

默认文件是按照字节为单位显示大小的

加了这个参数后，会附带K、M、G、T等大小后缀

K表示千字节 M表示兆字节 G表示1024兆 T表示1024G

虽然精准度下降了，但是更容易阅读

#### -R 递归访问

默认是显示当前目录下的文件和文件夹

带上R参数后，如果当前目录下有其他文件夹

则会将该文件夹下面的文件和文件夹也显示出来

所以该参数会显示指定位置下的所有文件和文件夹

#### -Q文件名用双引号包裹

这个参数是为了防止某些文件或者文件夹的末尾是空格字符

这样，可以通过双引号，看到文件名实际的长度
