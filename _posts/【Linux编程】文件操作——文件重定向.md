在操作系统层面提供了`dup2`对文件描述符进行重定向，在高级语言层面也需要一个接口对文件指针（文件流）进行重定向

### 文件指针重定向函数详解

---

#### 使用背景

在 Linux 系统编程中，存在两套重定向接口：

| 层级             | 接口      | 操作对象               | 说明                                               |
| ---------------- | --------- | ---------------------- | -------------------------------------------------- |
| **操作系统层面** | `dup2`    | 文件描述符 `fd`        | 对底层描述符进行重定向，适用于系统调用级别的 I/O   |
| **高级语言层面** | `freopen` | 文件指针 `FILE*`（流） | 对标准 I/O 流进行重定向，适用于 C 标准库级别的 I/O |

`freopen` 提供了与 `dup2` 类似的功能，但作用于 `FILE*` 流层面，使得 `printf`、`fprintf`、`fgets` 等标准 I/O 函数可以无缝切换到新文件。

---

#### `freopen` —— 文件指针重定向

##### 函数原型
```c
#include <stdio.h>

FILE *freopen(const char *filename, const char *mode, FILE *stream);
```

##### 功能说明
**原子性地替换**一个 `FILE` 流对象所关联的文件描述符，使其指向一个新文件。常用于标准输入、输出、错误流的重定向。

##### 返回值
- **成功**：返回传入的 `stream` 指针（即重定向后的流）。
- **失败**：返回 `NULL`，并设置 `errno`。

##### 所需头文件

| 头文件               | 必要性   | 说明                                                         |
| -------------------- | -------- | ------------------------------------------------------------ |
| `#include <stdio.h>` | **必须** | C 标准库规定 `freopen` 函数的声明及 `FILE` 类型定义位于 `<stdio.h>` 中。 |

##### 参数详解
| 参数       | 说明                                                        |
| ---------- | ----------------------------------------------------------- |
| `filename` | 要重定向到的目标文件路径                                    |
| `mode`     | 文件打开模式，与 `fopen` 相同（如 `"r"`、`"w"`、`"a"` 等）  |
| `stream`   | 要被重定向的流（如 `stdin`、`stdout`、`stderr` 或自定义流） |

##### 底层实现逻辑（技术本质）

`freopen` 的底层实现可以分为以下 5 个步骤：

1. **刷新旧流**：调用 `fflush(stream)` 将旧流中尚未输出的缓冲区数据强制写入内核，并清除流的错误和结束标志（EOF）。

2. **打开新文件**：使用 `open(filename, flags, mode)` 系统调用获取一个新的文件描述符 `new_fd`。`flags` 由传入的 `mode` 字符串（如 `"w"` 或 `"r"`）解析而来。

3. **重定向描述符**⭐：调用 **`dup2(new_fd, fileno(stream))`**。该系统调用会**原子地**关闭 `stream` 原本关联的文件描述符（`fileno(stream)`），然后让这个描述符直接指向 `new_fd` 所代表的那个内核文件对象。

4. **状态同步**：将新打开文件的状态（如文件位置指针、读写模式、缓冲区类型等）同步到旧的 `FILE` 结构体中，替换掉之前的状态信息。

5. **清理临时描述符**：调用 `close(new_fd)` 关闭临时描述符。由于描述符 `fileno(stream)` 已经指向了内核文件对象，关闭 `new_fd` 只是减少了一个引用计数，并不会关闭实际文件。

##### 关键特性

> `freopen` **没有改变 `FILE` 结构体本身的内存地址**（如 `stdin` 永远指向那片内存），但它改变了该结构体内部的 `_fileno` 字段和缓冲状态。因此，所有后续对该流（如 `printf` 操作 `stdout`）的读写操作，都会天然地作用于新文件。

##### 典型应用场景

1. **标准输出重定向到文件**：将 `printf` 的输出从终端重定向到日志文件。
2. **标准输入重定向到文件**：从文件读取数据代替键盘输入。
3. **标准错误重定向**：将错误信息记录到指定文件。

##### 使用示例

```c
#include <stdio.h>

int main() {
	FILE* pFile = freopen("./test.txt", "w+", stdout);
	if (pFile != NULL) {
		printf("%s(%d): %s\n", __FILE__, __LINE__, __FUNCTION__);
		fclose(pFile);
	}
	return 0;
}
```

##### 注意事项

1. **关闭旧文件**：`freopen` 会自动关闭 `stream` 原先关联的文件，无需手动 `fclose`。
2. **错误检查**：调用后应检查返回值是否为 `NULL`，以判断重定向是否成功。
3. **流的类型**：`stream` 必须是一个已打开的有效流。对于 `stdin`、`stdout`、`stderr`，它们在程序启动时默认打开。
4. **缓冲问题**：重定向前会先刷新缓冲区，确保旧数据不会丢失。
