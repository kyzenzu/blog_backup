### 文件操作函数详解

---

#### 1. `fopen` —— 打开文件（标准 I/O 库）

##### 函数原型
```c
#include <stdio.h>

FILE *fopen(const char *path, const char *mode);
```

##### 功能说明
打开指定路径的文件，并返回一个 `FILE*` 流指针，用于后续的读写操作。这是 C 标准库提供的高级文件操作接口，与 `open`（系统调用）不同，它提供了缓冲 I/O。

##### 返回值
- **成功**：返回指向 `FILE` 结构的指针。
- **失败**：返回 `NULL`，并设置全局 `errno`。

##### 所需头文件

| 头文件               | 必要性   | 说明                                                         |
| -------------------- | -------- | ------------------------------------------------------------ |
| `#include <stdio.h>` | **必须** | C 标准库规定 `fopen`、`fclose` 等标准 I/O 函数的声明，以及 `FILE` 类型定义均位于 `<stdio.h>` 中。 |

##### 参数详解
| 参数   | 说明                                   |
| ------ | -------------------------------------- |
| `path` | 要打开的文件路径（绝对路径或相对路径） |
| `mode` | 打开模式字符串，见下表                 |

##### `mode` 参数详解

| 模式     | 含义                           | 文件不存在          | 文件存在       |
| -------- | ------------------------------ | ------------------- | -------------- |
| **`r`**  | 只读                           | 返回 `NULL`（失败） | 从头开始读     |
| **`w`**  | 只写                           | 创建新文件          | 清空文件内容   |
| **`a`**  | 追加写入                       | 创建新文件          | 从文件末尾写入 |
| **`r+`** | 读写（主要还是想读，但允许写） | 返回 `NULL`（失败） | 从头开始读写   |
| **`w+`** | 读写（主要还是想写，但允许读） | 创建新文件          | 清空文件内容   |
| **`a+`** | 读写（追加模式）               | 创建新文件          | 从文件末尾读写 |

##### 模式修饰符

| 修饰符  | 含义                                                       |
| ------- | ---------------------------------------------------------- |
| **`b`** | 以**二进制**模式打开（如 `"rb"`、`"wb+"`）                 |
| **`t`** | 以**文本**模式打开（**默认模式**，如 `"rt"` 等同于 `"r"`） |

##### 权限说明
- `fopen` **不能指定权限**（与 `open` 不同）。
- 当文件需要创建时（使用 `w`、`w+`、`a`、`a+` 模式），文件权限由系统的 **umask** 决定。
- **默认权限**通常为 `rw-rw-r--`（664）或 `rw-r--r--`（644），具体取决于系统 umask 设置。

##### 使用示例
```c
int main() {
	FILE* pFile = fopen("./test.txt", "rt+");
	if (pFile != NULL) {
		printf("文件打开成功\n");
		fclose(pFile);
	} else {
		printf("文件打开失败\n");
	}
	return 0;
}
```

#### 2. `fclose` —— 关闭文件

##### 函数原型
```c
#include <stdio.h>

int fclose(FILE *fp);
```

##### 功能说明
关闭指定的文件流，将缓冲区中尚未写入的数据刷新到磁盘，释放与 `FILE*` 相关的所有资源。

##### 返回值
- **成功**：返回 `0`。
- **失败**：返回 `EOF`（即 `-1`），并设置 `errno`。

##### 所需头文件

| 头文件               | 必要性   | 说明                                                  |
| -------------------- | -------- | ----------------------------------------------------- |
| `#include <stdio.h>` | **必须** | C 标准库规定 `fclose` 函数的声明位于 `<stdio.h>` 中。 |

##### 注意事项
1. **缓冲区刷新**：`fclose` 会自动调用 `fflush`，将缓冲区数据写入磁盘。
2. **资源释放**：关闭后 `FILE*` 指针不再有效，不应再次使用。
3. **及时关闭**：进程可打开的文件数量有限，用完应及时关闭，避免资源泄漏。
4. **进程退出**：进程正常退出时，C 标准库会自动关闭所有已打开的文件流，但依赖此机制是不良习惯。

---

#### `fopen` 与 `open` 对比

| 特性         | `fopen`（标准 I/O）     | `open`（系统调用）           |
| ------------ | ----------------------- | ---------------------------- |
| **所属层级** | C 标准库（带缓冲）      | 系统调用（内核接口）         |
| **返回值**   | `FILE*` 流指针          | 文件描述符（`int`）          |
| **缓冲机制** | 带用户态缓冲区          | 无用户态缓冲（内核页缓存）   |
| **权限设置** | 受 umask 控制，不能指定 | 可通过 `mode` 参数指定       |
| **可移植性** | 高（跨平台）            | 低（Unix/Linux 特有）        |
| **适用场景** | 常规文件读写，文本处理  | 底层控制、网络编程、特殊设备 |
