### 文件读写位置函数详解

---

#### 为什么有两套文件读写位置函数？

在 C 标准库中，存在两套用于操作文件读写位置的函数：

| 函数族         | 代表函数              | 偏移量类型                     | 适用场景                                         |
| -------------- | --------------------- | ------------------------------ | ------------------------------------------------ |
| **传统函数族** | `fseek` / `ftell`     | `long`（通常 32 位）           | 适用于**小文件**（文件大小 < 2GB），简单易用     |
| **现代函数族** | `fgetpos` / `fsetpos` | `fpos_t`（可为 64 位或结构体） | 适用于**大文件**（文件大小 ≥ 2GB），可移植性更好 |

##### 设计原因
1. **历史演进**：早期 Unix 系统使用 `long` 类型（32 位）表示文件偏移量，最大只能支持 2GB 文件。随着文件越来越大，需要一种能支持更大文件的方式。
2. **`fpos_t` 的灵活性**：`fpos_t` 可以定义为 `long long`（64 位）或结构体类型，不限于整数，可以包含多字节字符状态等额外信息，适应不同平台的扩展需求。
3. **可移植性**：`fgetpos` / `fsetpos` 是 C 标准库提供的更现代的接口，推荐在新代码中使用。

##### 核心区别

| 特性             | `fseek` / `ftell`      | `fgetpos` / `fsetpos`                    |
| ---------------- | ---------------------- | ---------------------------------------- |
| **偏移量类型**   | `long`                 | `fpos_t`（可为结构体）                   |
| **最大文件支持** | 通常 2GB（32 位 long） | 支持超大文件（64 位或自定义）            |
| **额外状态**     | 不支持                 | 可存储多字节字符状态（如 `__mbstate_t`） |
| **C 标准**       | ANSI C（较早）         | ANSI C（较晚引入）                       |
| **推荐程度**     | 简单场景               | 大文件场景、可移植性要求高               |

### 一、`fseek` 和 `ftell`

#### 1. `fseek` —— 设置文件读写位置（传统版）

##### 函数原型
```c
#include <stdio.h>

int fseek(FILE *stream, long offset, int whence);
```

##### 功能说明
设置文件流 `stream` 的读写位置指针。位置由 `whence` 和 `offset` 共同决定：`whence` 指定起始点，`offset` 指定相对于起始点的偏移量。

##### 返回值
- **成功**：返回 `0`。
- **失败**：返回 `-1`（非零值），并设置 `errno`。

##### 所需头文件

| 头文件               | 必要性   | 说明                                                         |
| -------------------- | -------- | ------------------------------------------------------------ |
| `#include <stdio.h>` | **必须** | C 标准库规定 `fseek`、`ftell`、`fgetpos`、`fsetpos` 等文件定位函数的声明及 `SEEK_SET`、`SEEK_CUR`、`SEEK_END` 宏定义位于 `<stdio.h>` 中。 |

##### 参数详解

| 参数     | 说明                            |
| -------- | ------------------------------- |
| `stream` | 指向 `FILE` 结构的文件流指针    |
| `offset` | 偏移量（字节数），类型为 `long` |
| `whence` | 起始位置，可选三个常量          |

##### `whence` 取值

| 常量       | 值   | 含义                   | `offset` 符号 |
| ---------- | ---- | ---------------------- | ------------- |
| `SEEK_SET` | 0    | 从**文件开头**开始偏移 | **必须 ≥ 0**  |
| `SEEK_CUR` | 1    | 从**当前位置**开始偏移 | 可为负数      |
| `SEEK_END` | 2    | 从**文件末尾**开始偏移 | 可为负数      |

> **最终位置** = `whence` 指定的起始点 + `offset`

##### 重要特性
- ⭐`fseek` 可以将读写位置设置到**超过文件实际大小**的位置（即文件空洞），此时若执行写入操作，文件会扩展，中间的空缺部分用 `0` 填充。
- `fseek` 会清除文件流的 EOF（文件结束）指示器。

#### 2. `ftell` —— 获取当前读写位置（传统版）

##### 函数原型
```c
#include <stdio.h>

long ftell(FILE *stream);
```

##### 功能说明
获取文件流 `stream` 当前读写位置相对于**文件开头**的偏移量（字节数）。

##### 返回值
- **成功**：返回当前读写位置的偏移量（`long` 类型，从文件开头计算）。
- **失败**：返回 `-1L`，并设置 `errno`。

> **⚠️ 注意**：成功返回的偏移量可能为 `-1`（当位置恰好是 `-1` 字节时），此时需结合 `errno` 判断是否出错：
> ```c
> errno = 0;
> long pos = ftell(fp);
> if (pos == -1L && errno != 0) {
>  perror("ftell failed");
> }
> ```

##### 使用示例
```c
FILE *fp = fopen("test.txt", "r");
if (fp != NULL) {
    fseek(fp, 100, SEEK_SET);   // 跳到文件开头偏移 100 字节处
    long pos = ftell(fp);       // 获取当前位置
    printf("当前位置: %ld\n", pos);  // 输出: 100
    fclose(fp);
}
```

### 二、`fsetpos` 和 `fgetpos`

#### 1. `fsetpos` —— 设置文件读写位置（现代版）

##### 函数原型

```c
#include <stdio.h>

int fsetpos(FILE *stream, const fpos_t *pos);
```

##### 功能说明

将文件流 `stream` 的读写位置设置为 `pos` 所指定的位置（`pos` 通常由 `fgetpos` 获取）。

##### 返回值

- **成功**：返回 `0`。
- **失败**：返回非零值，并设置 `errno`。

##### 参数详解

| 参数     | 说明                                         |
| -------- | -------------------------------------------- |
| `stream` | 指向 `FILE` 结构的文件流指针                 |
| `pos`    | 指向 `fpos_t` 结构体的指针，包含目标位置信息 |

##### `fpos_t` 结构体定义（glibc 实现）

```c
struct fpos_t {
    __off_t __pos;          // 文件偏移量
    __mbstate_t __state;    // 多字节字符状态（用于宽字符转换）
};

struct __mbstate_t {
    int __count;
    int __value;            /* Value so far. */
};
```

##### 使用示例

```c
FILE *fp = fopen("test.txt", "r");
if (fp != NULL) {
    fpos_t pos;

    // 1. 获取当前位置
    fgetpos(fp, &pos);
    printf("当前位置已保存\n");

    // 2. 执行一些读取操作...

    // 3. 恢复到之前保存的位置
    fsetpos(fp, &pos);
    printf("已恢复至保存的位置\n");

    fclose(fp);
}
```

> **注意**：`fsetpos` 通过修改 `pos.__pos` 的值来跳转（在实现层面），但开发者应当将其视为**不透明类型**，只通过 `fgetpos` 获取和 `fsetpos` 设置，**不应手动修改其内部字段**

#### 2. `fgetpos` —— 获取当前读写位置（现代版）

##### 函数原型
```c
#include <stdio.h>

int fgetpos(FILE *stream, fpos_t *pos);
```

##### 功能说明
获取文件流 `stream` 当前读写位置，并将其存储到 `pos` 指向的 `fpos_t` 结构体中。

##### 返回值
- **成功**：返回 `0`。
- **失败**：返回非零值，并设置 `errno`。

##### 所需头文件

| 头文件               | 必要性   | 说明                                                         |
| -------------------- | -------- | ------------------------------------------------------------ |
| `#include <stdio.h>` | **必须** | C 标准库规定 `fgetpos` 和 `fsetpos` 的函数声明以及 `fpos_t` 类型定义位于 `<stdio.h>` 中。 |

##### 参数详解
| 参数     | 说明                                             |
| -------- | ------------------------------------------------ |
| `stream` | 指向 `FILE` 结构的文件流指针                     |
| `pos`    | 指向 `fpos_t` 结构体的指针，用于存储当前位置信息 |

> **注意**：`fpos_t` **不仅仅是整数**，它是一个结构体，除了偏移量外还可能包含多字节字符转换的状态，因此更适合处理宽字符文件。

##### 使用示例

```c
FILE *fp = fopen("test.txt", "r");
if (fp != NULL) {
    fpos_t pos;

    fgetpos(fp, &pos);
    pos.__pos += 1; // 通过修改 pos.__pos 值进行跳转
    fsetpos(fp, &pos);
    
    fgetc(fp);

    fclose(fp);
}
```

> **注意**：`fsetpos` 通过修改 `pos.__pos` 的值来跳转（在实现层面），但开发者应当将其视为**不透明类型**，只通过 `fgetpos` 获取和 `fsetpos` 设置，**不应手动修改其内部字段**

#### 选择建议

| 场景                            | 推荐函数              | 原因                       |
| ------------------------------- | --------------------- | -------------------------- |
| 文件大小 < 2GB，且不涉及宽字符  | `fseek` / `ftell`     | 简单直观，调用方便         |
| 文件大小 ≥ 2GB，或需要可移植性  | `fgetpos` / `fsetpos` | 支持大文件，平台适应性更好 |
| 处理多字节字符集文件            | `fgetpos` / `fsetpos` | 可保存字符转换状态         |
| 需要保存/恢复位置（如递归解析） | `fgetpos` / `fsetpos` | 位置信息更完整             |
