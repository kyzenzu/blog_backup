### `fwrite`  函数详解

---

#### 1. `fwrite` —— 写入数据到文件流

##### 函数原型
```c
#include <stdio.h>

size_t fwrite(const void *ptr, size_t size, size_t nmemb, FILE *stream);
```

##### 功能说明
将 `ptr` 指向的内存缓冲区中的数据写入到文件流 `stream` 中。`fwrite` 以**元素（单位）** 为基本写入单元，每次写入一个元素，元素的大小由 `size` 指定，写入的元素个数由 `nmemb` 指定。

##### 返回值
- **成功**：返回**实际写入的元素（单位）个数**，而不是写入的字节数。
- **出错**：返回值小于 `nmemb`，应使用 `ferror(stream)` 检查具体错误原因。
- **返回值类型**：`size_t`（无符号整数）。

> **⚠️ 重要**：`fwrite` 的返回值是**元素个数**，不是字节数。这与系统调用 `write` 不同（`write` 按字节写入，返回值为字节数）。

##### 所需头文件

| 头文件               | 必要性   | 说明                                                         |
| -------------------- | -------- | ------------------------------------------------------------ |
| `#include <stdio.h>` | **必须** | C 标准库规定 `fwrite`、`fread` 等标准 I/O 读写函数的声明及 `FILE` 类型定义位于 `<stdio.h>` 中。 |

##### 参数详解

| 参数     | 说明                                                        |
| -------- | ----------------------------------------------------------- |
| `ptr`    | 指向内存缓冲区的指针，包含要写入的数据                      |
| `size`   | **每个元素（单位）的大小**（字节数）                        |
| `nmemb`  | **要写入的元素（单位）个数**                                |
| `stream` | 指向 `FILE` 结构的文件流指针（由 `fopen`、`fdopen` 等返回） |

##### 核心要点

1. **写入单位（元素）**：`fwrite` 以元素为单位进行写入，每次写入 `size` 字节作为一个完整元素。
2. **总写入字节数** = `size × nmemb`（请求的总字节数）。
3. **返回值含义**：返回的是**成功写入的元素个数**，而不是字节数。
4. **缓冲行为**：`fwrite` 写入的数据先进入用户态缓冲区，并不会立即写入磁盘。如需强制落盘，应调用 `fflush` 或 `fsync`。

---

#### 2. 使用示例

```c
#include <stdio.h>

struct Test {
    int id;
    char name[64];
    int age;
};

int main() {
    // ========== 写入数据 ==========
    FILE* pFile = fopen("./test", "wb+");
    if (pFile != NULL) {
        struct Test data = {
            1000,
            "Tiger",
            28
        };

        // 写入 1 个元素，每个元素大小为 sizeof(Test)
        int ret = fwrite(&data, sizeof(struct Test), 1, pFile);
        printf("fwrite: %d\n", ret);  // 输出: fwrite: 1

        // 强制刷新缓冲区，确保数据写入磁盘
        fflush(pFile);
        fclose(pFile);
    }

    // ========== 读取数据 ==========
    pFile = fopen("./test", "rb");
    if (pFile != NULL) {
        struct Test data;

        // 读取 sizeof(Test) 个元素，每个元素大小为 1 字节
        // 注意：这里 size=1, nmemb=sizeof(Test)，等价于按字节读取
        int ret = fread(&data, 1, sizeof(struct Test), pFile);
        printf("fread: %d\n", ret);   // 输出: fread: 72
        printf("data: {%d, %s, %d}\n", data.id, data.name, data.age);
        // 输出: data: {1000, Tiger, 28}

        fclose(pFile);
    }

    return 0;
}
```

##### 输出结果
```
fwrite: 1
fread: 72
data: {1000, Tiger, 28}
```

##### 关键解析

| 操作                                    | 参数                 | 含义                                | 返回值                      |
| --------------------------------------- | -------------------- | ----------------------------------- | --------------------------- |
| `fwrite(&data, sizeof(Test), 1, pFile)` | `size=72`, `nmemb=1` | 写入 **1 个元素**，每个元素 72 字节 | 返回 `1`（写入 1 个元素）   |
| `fread(&data, 1, sizeof(Test), pFile)`  | `size=1`, `nmemb=72` | 读取 **72 个元素**，每个元素 1 字节 | 返回 `72`（读取 72 个元素） |

> **两种写法等价**：`fwrite(buf, 72, 1, fp)` 和 `fwrite(buf, 1, 72, fp)` 都写入 72 字节，但返回值不同（前者返回 `1`，后者返回 `72`）。

---

#### 3. 与 `write` 系统调用的区别

| 特性           | `fwrite`（标准 I/O）                 | `write`（系统调用）               |
| -------------- | ------------------------------------ | --------------------------------- |
| **所属层级**   | C 标准库（带用户态缓冲）             | 系统调用（内核接口）              |
| **写入单位**   | 元素（单位），由 `size` 指定         | 字节                              |
| **返回值含义** | 写入的**元素个数**                   | 写入的**字节数**                  |
| **缓冲机制**   | 用户态缓冲区（需 `fflush` 强制刷新） | 内核页缓存（可直接 `fsync` 落盘） |
| **适用场景**   | 结构化数据写入（如数组、结构体）     | 原始字节流写入、底层控制          |

---

#### 快速参考

| 函数     | 头文件      | 核心用途         | 返回值         |
| -------- | ----------- | ---------------- | -------------- |
| `fwrite` | `<stdio.h>` | 向文件流写入数据 | 写入的元素个数 |

### `fputc` 和 `fputs` 函数详解

---

#### 1. `fputc` —— 写入一个字符

##### 函数原型
```c
#include <stdio.h>

int fputc(int c, FILE *stream);
```

##### 功能说明
将指定的字符 `c` 写入到文件流 `stream` 中，写入位置由文件流内部的读写位置指针决定。写入后，位置指针会自动向后移动一个字符。

##### 返回值
- **成功**：返回写入的字符（转换为 `unsigned char` 后的 `int` 值）。
- **失败**：返回 `EOF`（通常为 `-1`），并设置 `errno`。

##### 所需头文件

| 头文件               | 必要性   | 说明                                                         |
| -------------------- | -------- | ------------------------------------------------------------ |
| `#include <stdio.h>` | **必须** | C 标准库规定 `fputc`、`fputs` 等字符/字符串写入函数的声明及 `FILE` 类型定义、`EOF` 宏定义位于 `<stdio.h>` 中。 |

##### 参数详解
| 参数     | 说明                                                         |
| -------- | ------------------------------------------------------------ |
| `c`      | 要写入的字符（以 `int` 形式传入，实际写入时会转换为 `unsigned char`） |
| `stream` | 指向 `FILE` 结构的文件流指针（由 `fopen`、`fdopen` 等返回）  |

##### 核心行为
- `fputc` 是**覆盖写入**，将字符写入到文件流当前位置指针指向的位置，**不是插入**。
- 写入后，文件流的位置指针会自动前进 1 个字符。

---

#### 2. `fputs` —— 写入一个字符串

##### 函数原型
```c
#include <stdio.h>

int fputs(const char *str, FILE *stream);
```

##### 功能说明
将字符串 `str` 写入到文件流 `stream` 中，从当前文件位置指针指向的位置开始写入。

##### 返回值
- **成功**：返回一个非负值（通常为 `0`）。
- **失败**：返回 `EOF`（通常为 `-1`），并设置 `errno`。

##### 所需头文件

| 头文件               | 必要性   | 说明                                                 |
| -------------------- | -------- | ---------------------------------------------------- |
| `#include <stdio.h>` | **必须** | C 标准库规定 `fputs` 函数的声明位于 `<stdio.h>` 中。 |

##### 参数详解
| 参数     | 说明                                   |
| -------- | -------------------------------------- |
| `str`    | 指向要写入的字符串（必须以 `\0` 结尾） |
| `stream` | 指向 `FILE` 结构的文件流指针           |

##### 核心行为
- `fputs` 是**覆盖写入**，将字符串写入到文件流当前位置指针指向的位置，**不是插入**。
- 只有遇到 `str` 中的 `\0` 字符时，才会**终止写入**（`\0` 本身不会被写入文件）。

##### ⚠️ 重要警告

> **`str` 必须是标准 C 语言字符串（以 `\0` 或空字符为结尾的字符串）**，否则 `fputs` 会**无止境地**向硬盘中写入数据，直到遇到内存中的 `\0` 为止，这可能导致：
> - 无止境的向磁盘写入
> - 程序崩溃（访问非法内存）
> - 数据损坏

---

#### 3. 文件流内部读写指针

`FILE` 结构体内部维护了**读写位置指针**，记录了当前文件流中下一次读/写操作的位置。

- 每次调用 `fgetc`、`fgets`、`fread`、`fwrite` 等函数，都会**自动更新**该位置指针。
- ⭐**读指针和写指针在同一个文件流中共享同一个位置**（对于 `r+`/`w+` 等读写模式，读写操作**共用同一个位置指针**）。

#### 快速参考

| 函数    | 头文件      | 核心用途               | 返回值             |
| :------ | :---------- | :--------------------- | :----------------- |
| `fputc` | `<stdio.h>` | 向文件流写入一个字符   | 写入的字符或 `EOF` |
| `fputs` | `<stdio.h>` | 向文件流写入一个字符串 | 非负值或 `EOF`     |

### `fflush` 函数详解

#### `fflush` —— 刷新缓冲区

##### 函数原型

```c
#include <stdio.h>

int fflush(FILE *stream);
```

##### 功能说明

将文件流 `stream` 的用户态缓冲区中尚未写入的数据**强制刷新**到底层内核（或磁盘）。

##### 返回值

- **成功**：返回 `0`。
- **失败**：返回 `EOF`（通常为 `-1`），并设置 `errno`。

##### 所需头文件

| 头文件               | 必要性   | 说明                                                  |
| -------------------- | -------- | ----------------------------------------------------- |
| `#include <stdio.h>` | **必须** | C 标准库规定 `fflush` 函数的声明位于 `<stdio.h>` 中。 |

##### 参数详解

| 参数     | 说明                                                         |
| -------- | ------------------------------------------------------------ |
| `stream` | 指向 `FILE` 结构的文件流指针。传入 `NULL` 表示刷新**所有**已打开的输出流。 |

##### 核心行为

- **输出流**（如 `stdout`、文件写流）：将缓冲区数据写入内核。
- **输入流**（如 `stdin`、文件读流）：行为未定义（不应在输入流上调用 `fflush`）。
- **`stream == NULL`**：刷新所有输出流。
